# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
  
## PROCEDURE

1. Open Autodesk Fusion 360 and create a new design.

2. Select Create Sketch and choose the XY plane.

3. Draw a vertical construction line through the origin using the Line tool to establish the centre axis of the profile.
<img width="358" height="352" alt="image" src="https://github.com/user-attachments/assets/31d30379-3eae-4dd7-8045-4bf162bd0491" />

4. Draw the top circle with a diameter of Ø20 mm and create the outer top arc with a diameter of Ø32 mm.
<img width="246" height="307" alt="image" src="https://github.com/user-attachments/assets/53cea619-605b-470c-8bb0-7057d9bbb108" />

5. Draw the main body profile using the Line, Arc and Tangent Arc tools, maintaining symmetry about the centre axis.

6. Create the curved side portions using the Arc tool and apply the radius dimensions R64 on both sides.

![image](https://user-images.githubusercontent.com/113594316/198206621-6348e8a3-4bbd-4a1f-96d3-db16fbf933d9.png)
7. Draw the central opening using arcs and lines, and apply the required dimensions, including Ø40, R6 and Ø66, as shown in the given drawing.
![image](https://user-images.githubusercontent.com/113594316/198206639-31c4bdb5-b13e-4106-bcf5-125c294aa03e.png)
8. Create the lower side extensions using arcs and apply the radius dimensions R20, R10 and R7 as specified in the drawing.

9. Draw the bottom circular portion at the centre using the Circle tool and set its diameter to Ø10 mm. Complete the surrounding outer profile with the required R20 curve.

10. Apply the necessary dimensions using the Sketch Dimension (D) tool, including the vertical dimensions 65 mm, 26 mm and 24 mm, and horizontal dimensions 47 mm on both sides.
![image](https://user-images.githubusercontent.com/113594316/198206697-2e3ead2b-7d1e-436e-bc36-aa2e73c1e78e.png)

11. Use the Trim (T) tool to remove unwanted lines and arcs and ensure that the sketch forms the required profile.

12. Apply geometric constraints such as Symmetry, Tangent, Coincident and Horizontal/Vertical to maintain the accuracy of the sketch.

13. Check all dimensions and ensure that the sketch is fully constrained wherever possible.

14. Click Finish Sketch to complete the 2D sketch.

![image](https://user-images.githubusercontent.com/113594316/198206721-8ad45462-2675-4be2-964f-621c8fc4490e.png).
